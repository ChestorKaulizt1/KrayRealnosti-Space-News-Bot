# КРАЙ РЕАЛЬНОСТИ — Space News Bot

Автоматический сборщик космических новостей для Telegram-канала «КРАЙ РЕАЛЬНОСТИ».

## Что умеет проект

- получает новости из RSS;
- проверяет статьи на соответствие космической тематике;
- отбрасывает нерелевантные материалы;
- сохраняет обработанные новости в SQLite;
- не добавляет одну и ту же ссылку повторно;
- выводит найденные новости в консоль.

## Источники

Сейчас подключены:

- NASA
- ESA
- Space.com
- Universe Today
- ScienceAlert
